Устали от необходимости менять масштаб в приложениях Google Workspace при первой загрузке из-за слишком мелкого текста? Это должно помочь.

Это расширение позволит вам установить «масштаб по умолчанию» для следующих приложений Google Workspace:

- Google Docs
- Google Sheets

После установки желаемого уровня масштабирования, он будет изменяться при каждой загрузке приложения Google Workspace.

Если вы хотите помочь мне с переводом на другие языки, кроме английского, пожалуйста, свяжитесь со мной!

Эта версия включает в себя функциональность для настройки пользовательских уровней масштабирования, для работы которой требуются расширенные права доступа к браузеру. Из-за этого изменения вы можете увидеть сообщение «'Масштаб по умолчанию для Google Workspace (расширенный)' начал отладку этого браузера».

Пожалуйста, не беспокойтесь. Это обычное сообщение, подтверждающее корректную работу расширения. Вы можете смело его игнорировать.

Не волнуйтесь! Если вы не хотите принимать расширенные права доступа, вы можете использовать мое другое расширение, которое позволяет использовать предопределенные значения масштабирования. Приложение доступно здесь (https://chrome.google.com/webstore/detail/google-workspace-zoom-def/nflkcdlimipkgbacnfnhfecjgmojhklo).
