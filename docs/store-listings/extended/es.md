¿Cansado de tener que cambiar el zoom en tus aplicaciones de Google Workspace al abrirlas porque el texto es demasiado pequeño? ¡Esto te ayudará!

Esta extensión te permitirá establecer un zoom predeterminado para las siguientes aplicaciones de Google Workspace:

- Google Docs
- Google Sheets

Una vez que configures el nivel de zoom deseado, este se ajustará automáticamente al abrir cualquier aplicación de Google Workspace.

Si quieres ayudarme a traducir esto a otros idiomas, ¡contáctame!

Esta versión incluye la funcionalidad para configurar niveles de zoom personalizados, lo cual requiere permisos de administrador en el navegador. Debido a este cambio, es posible que veas un mensaje que dice: "'Zoom predeterminado para Google Workspace (Extendido)' ha comenzado a depurar este navegador".

No te preocupes. Este es un mensaje normal que confirma que la extensión funciona correctamente. Puedes ignorarlo sin problema.

¡No te preocupes! Si no quieres aceptar los permisos de administrador, puedes usar mi otra extensión, que permite usar valores de zoom predefinidos. Está disponible aquí (https://chrome.google.com/webstore/detail/google-workspace-zoom-def/nflkcdlimipkgbacnfnhfecjgmojhklo).
