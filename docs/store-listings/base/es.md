¿Cansado de tener que cambiar el zoom en tus aplicaciones de Google Workspace al abrirlas porque el texto es demasiado pequeño? ¡Esto te ayudará!

Esta extensión te permitirá establecer un zoom predeterminado para las siguientes aplicaciones de Google Workspace:

- Google Docs
- Google Sheets

Una vez que configures el nivel de zoom deseado, este se ajustará automáticamente cada vez que abras una aplicación de Google Workspace.

Si quieres ayudarme a traducir esto a otros idiomas, ¡contáctame!

Si prefieres usar tus propios valores de zoom personalizados, consulta mi otra extensión (https://chrome.google.com/webstore/detail/google-workspace-zoom-def/mdgikencgfhineaememjagpkiclbdkka).
