Vous en avez assez de devoir modifier le zoom de vos applications Google Workspace dès leur ouverture car le texte est trop petit ? Cette extension devrait vous aider.

Elle vous permet de définir un niveau de zoom par défaut pour les applications Google Workspace suivantes :

- Google Docs
- Google Sheets

Une fois votre niveau de zoom défini, il sera automatiquement ajusté à chaque ouverture d'une application Google Workspace.

Si vous souhaitez m'aider à traduire cette extension dans d'autres langues que l'anglais, n'hésitez pas à me contacter !

Si vous préférez utiliser vos propres valeurs de zoom personnalisées, découvrez mon autre extension (https://chrome.google.com/webstore/detail/google-workspace-zoom-def/mdgikencgfhineaememjagpkiclbdkka).
