---
topic: Formatting rules (oxfmt)
---

.oxfmtrc.json sets printWidth 100, 2-space indent, semicolons, double quotes, trailingComma "none", bracketSameLine true. oxlint (.oxlintrc.json) uses the react, typescript, jsx-a11y and import plugins with the correctness category at "warn". Files are kebab-case (get-current-app.ts); components are PascalCase directories.
